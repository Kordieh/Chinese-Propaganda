# Tarea 3 - Alejandro Betanzo

## Tema

El tema de esta crónica es el nacimiento de la industria de videojuegos y la llegada de China al mercado.

## Descripción

Esta página muestra una pieza individual de caracter narrativo, cuyo enfoque principal es el hablar resumidamente del inicio de la industria de videojuegos a modo de contexto básico inicial.

La idea es dar este puntapie para introducir el cómo Asia jugó un rol fundamental en la industria, específicamente Japón (como un actor de relevancia especialmente en los primeros años), y a día de hoy China, quien es el actor principal de este universo narrativo.

Se apoya en la visualización de datos de las importaciones y exportaciones de productos culturales, específicamente aquellos catalogados como "Software y videojuegos" según las definiciones y parámetros entregados por Naciones Unidas.

## Proceso

Lo primero que hice para armar la pieza individual fue escribir la información y la estructura en texto plano, sin enlaces ni imágenes. Una vez realizado eso, comencé a darle un formato utilizando las herramientas HTML vistas en clases, usando etiquetas básicas como ```head```, ```body```,```img```,```h1, h2, h3``` y ```p```.

Cuando ya tuve el formato listo, procedí a la colocación de las imágenes y sus respectivos pies de página, con el fin de contextualizar cada una y que no quedaran colocadas "al aire", sino que se entendiera el motivo por el que estaban allí.
